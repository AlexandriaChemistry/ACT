alexandria::ForceField Class Reference

#include <act/forcefield/forcefield.h>

Description

The complete force field.

Holds the particle types, the parameter lists for all interaction types, the symmetric charges and general properties such as the charge generation algorithm and polarizability.

void alexandria::ForceField::convertCoulomb ( MsgHandler * msghandler)

Take the charge distributions from the interaction COULOMB In older force field files the width of the charge distribution of a particle type, zeta, is a parameter of the interaction COULOMB, to which the option zetatype of the particle type refers. Particle types that share a zetatype get a copy each. The number of exclusions, which has to be the same for COULOMB and VANDERWAALS, the distribution of the charges, the function of COULOMB, and the relative dielectric constant are options of COULOMB there. They become a parameter of the particle types and options of the particle types.
