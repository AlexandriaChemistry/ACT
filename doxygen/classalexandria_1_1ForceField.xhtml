alexandria::ForceField Class Reference

#include <act/forcefield/forcefield.h>

Description

The complete force field.

Holds the particle types, the parameter lists for all interaction types, the symmetric charges and general properties such as the charge generation algorithm and polarizability.

◆ calcDependent()

void alexandria::ForceField::calcDependent ( )

Compute dependent parameters.

The force field may contain a number of parameters that depend on othe parameters. For instance, the distance r_{ik} in an angle triplet r_{ijk} depends on the distances r_{ij} and r_{kj} as well as the angle between the vectors. Those dependent properties are computed here in order to get the highest accuracy in the numbers. This is important when computing energies based on these distances.

◆ convertVsite1()

void alexandria::ForceField::convertVsite1 ( MsgHandler * msghandler)

Replace virtual sites on top of atoms by a second charge Force field files may contain virtual sites of type VSITE1 that only carry a charge, on top of an atom. These are replaced by a second charge of the atom type, see ParticleType::chargeVS, which takes the charge, the width of the charge distribution and the row of the virtual site. The virtual site types and their parameters are removed. Virtual sites that have other interactions, for instance Van der Waals parameters, are kept.

Parameters
[in]msghandlerFor messages, may be nullptr

◆ expandSecondCharges()

void alexandria::ForceField::expandSecondCharges ( MsgHandler * msghandler)

Replace second charges by virtual sites on top of the atoms The inverse of convertVsite1, for programs that do not support second charges, such as GROMACS and OpenMM. Each atom type with a second charge gets a virtual site type of type VSITE1 that carries the charge, with the width and row of the second charge. Its other nonbonded parameters are those of the atom with the energy scaled to zero.

Parameters
[in]msghandlerFor messages, may be nullptr
