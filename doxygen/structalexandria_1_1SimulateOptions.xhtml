Description

What alexandria simulate does, as its command line gives it.

The program fills it from the command line, a program without one sets the members. runSimulate checks it, see check.

std::optional<ReRunner> alexandria::SimulateOptions::rerun

The energies of the structures of a trajectory instead of a simulation (-traj and the options for dimers).

Without it, or without a trajectory in its generator of dimers, the molecule is simulated. A program without a command line sets the trajectory with DimerGenerator::setTrajectory and calls DimerGenerator::finishSettings.
