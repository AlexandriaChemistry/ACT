Description

Input files of the tests: force fields, molprop files with their selections, and molecules, see README.md there.

Test data

The input files of the tests of ACT. The tests find them with gmx::test::TestFileManager::getInputFilePath(), which looks in the directory of the test first and then here (GMX_TESTSIMULATIONDATABASE_DIR in src/buildinfo.h.cmakein), so a test refers to a file as, for instance, forcefields/ACS-g1.xml. The reference data of the tests stay in the refdata directories next to the tests.

Directory Contents
forcefields Force fields (alexandria_chemistry XML files), and the input of gen_ff: atom types (CSV) and virtual sites (JSON). getForceField("name") reads forcefields/name.xml.
molprop Molprop files (molecules XML files) and their selection files (.dat), and make_subsets.py, which made the small molprop files of the train_ff tests.
molecules Structures (SDF, PDB, XYZ) and Gaussian output files.
other Gene pools of the GA tests, a table, and GROMACS files that no test uses.
