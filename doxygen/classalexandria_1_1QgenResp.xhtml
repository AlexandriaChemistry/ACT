alexandria::QgenResp Class Reference

#include <act/qgen/qgen_resp.h>

Description

Class to fit and evaluate charges against an electrostatic potential Holds the atoms (charges, distribution widths, coordinates) and a set of grid points with reference and calculated electrostatic potential. It can fit charges to the potential (RESP-like, with total charge and symmetry constraints), compute statistics and write cube files.
