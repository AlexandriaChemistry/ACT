alexandria::gpu::OutOfMemory Class Reference

#include <act/gpu/gpu.h>

Inherits std::bad_alloc.

Description

The GPU has no memory left for what a process puts on it Thrown by the GPU code instead of using an allocation that failed. The message tells how much memory the process has on the GPU, how many processes share it, whether the NVIDIA multi-process service runs, and what to do, see outOfMemoryMessage. As a std::bad_alloc, the program stops with "Memory allocation failed" and this message.
