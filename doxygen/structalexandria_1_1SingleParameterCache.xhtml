Description

The single particle types of a parameter list and their pairs Finding the single particle types means going through all entries of the list, which contains all pairs too, and sorting them. Since this is done after each change of a parameter during training, the result is kept, together with pointers to the pair entries. They stay valid as long as entries are only added, see ForceFieldParameterList::structureVersion, and the number of entries does not change.
