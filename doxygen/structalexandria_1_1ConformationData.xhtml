◆ activeKnown

size_t alexandria::ConformationData::activeKnown = 0

The number of conformations if all that are not in active are done, such that the next calculation leaving out those that are done only has to visit the conformations in active, see CoordsEnergy::done. Zero if that is not known.

◆ constructVsites

bool alexandria::ConformationData::constructVsites = false

Whether the next energy calculation has to construct the virtual sites of the conformations first.

◆ doublePrecision

bool alexandria::ConformationData::doublePrecision = false

Whether to compute the potentials in double precision in a single precision build, for methods that need it such as the normal mode analysis. The coordinates are then copied to arraysDouble and the forces back to arrays. Potentials without explicit SIMD, and single conformations, are still computed in real precision.

◆ spreadVsites

bool alexandria::ConformationData::spreadVsites = false

Whether the energy calculations spread the forces on the virtual sites over their parents, in the arrays if these are used. This is done in each calculation, which does not change the forces on the shells, but saves spreading them afterwards.
