Compute the chi-squared for each set of changed parameters The points are done in batches of one for the master and one for each worker. The master computes the first point of a batch itself, the workers get a copy of the genome with the changes applied and compute the chi-squared of the training set, see ACTMiddleMan::run. On return the genome and the force field are as on entry.
