Description

Tests that updating the force field one parameter at a time, as the MCMC steps of training do, gives the same results as filling all parameters from scratch.

Training only updates what depends on the parameters that changed: the topology entries of their interaction types, the parameters of the non-bonded pairs, the charges, and on the GPU the rows of the parameter tables. Each of these keeps track of versions to know what to do again. A mistake there gives energies of a mix of old and new parameters, which a test of a single evaluation does not find. Here, for each kind of parameter of a force field, the parameter is changed in one set of molecules that was evaluated before, as in an MCMC step, and the result is compared with that of another set of molecules that is evaluated for the first time, with the same parameters. Then the change is undone, as for a rejected step, which has to give the result from before again.
