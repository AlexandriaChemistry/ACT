Description

template<typename Use, typename One1, typename One2>
struct alexandria::OneSelect< Use, One1, One2 >

Two functions computing one interaction The first one is used for interactions for which use returns true, the second one otherwise. This allows a cheaper function to be used for some interactions, deciding once per interaction rather than in the loop over conformations.
