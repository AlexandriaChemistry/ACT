Description

template<typename C>
class alexandria::CoordinateVectors< C >

Integer coordinates of the particles of one conformation, without owning them As ParticleVectors, with the components stored as integers in units of coordinateUnit, see coordinate.h. A component reads as a value in nm, a value in nm assigned to it is rounded to the nearest unit, it has to be within the range, see toCoordinate. Assigning one component to another copies the integer, which is exact, and the difference of two vectors is computed from the integers.
