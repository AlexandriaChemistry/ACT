alexandria::DimerGenerator Class Reference

#include <act/properties/dimergenerator.h>

Description

Generate dimer coordinates from two monomers by sampling relative orientations (see RandAlg) and series of center of mass distances, or read them from a trajectory.

◆ generateRandomNumbers()

void alexandria::DimerGenerator::generateRandomNumbers ( int ndimers)

Generate the random numbers for all rotations For each orientation there are 6 numbers between 0 and 1, three for the Euler angles of each molecule, see Rotator::randomRotate. With the Gauss algorithm, the orientations are the points of the grid and there is a seventh number, the weight of the orientation.

Parameters
[in]ndimersThe number of dimers, not used for the Gauss algorithm
