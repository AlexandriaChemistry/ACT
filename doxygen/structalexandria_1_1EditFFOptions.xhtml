alexandria::EditFFOptions Struct Reference

#include <act/forcefield/edit_ff.h>

Description

What alexandria edit_ff does, as its command line gives it.

The program fills it from the command line, a program without one sets the members. runEditFF checks it, see check. One thing is done, the first of: with a second force field, copying, replacing or implanting its parameters, or else comparing the two; checking the bounds; validating; analysing or plotting; fixing or releasing the force constants of shells; removing particle types; signing, see sign; changing parameters. The combination rules are applied after any of these.
