◆ orderImproper()

void alexandria::Topology::orderImproper ( const ForceField * pd,
std::vector< Bond > * bonds ) const

Order the neighbours of the central atom of an improper The identifier of an improper depends on the order of the three neighbours, which would then depend on the numbering of the atoms. They are sorted by bond order and bond type, and the first order that the force field has parameters for is used.

Parameters
[in]pdThe force field, nothing is done if nullptr
[in,out]bondsThe bonds from the central atom to the neighbours
