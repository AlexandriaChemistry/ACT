alexandria::GpuBatch Class Reference

#include <act/forces/forces_gpu.h>

Description

Potentials of several molecules that are computed on the GPU at once computeEnergies first adds the interactions of all molecules that the GPU can compute, then computes them together, then uses the results where each molecule would compute them, see lowComputeEnergiesT. One GPU calculation for all molecules takes about as long as one for one molecule, since the time to start it dominates for small molecules.
