Description

The combination rules as functions for the processor and the GPU.

The formulas of the combination rules exist only here. The processor uses them through combinationrules.h, with the functions of the standard library (StdMath), and GPU code can instantiate them with those of SYCL. Therefore these functions do not throw and use no strings or containers: the functions of combinationrules.h check the input and report errors. The expressions are those that ACT used before, in the same order, such that results do not change.
