alexandria::CombinationPlan Class Reference

#include <act/forcefield/combinationrules.h>

Description

The combination of the parameters of one potential, for many pairs evalCombinationRule looks up the rule, unit and position of each parameter by name for every pair. During training the pairs of a particle type are made again after each change of its parameters, therefore this does the lookups once, for particle types that have the same parameters as the one it was made for.
