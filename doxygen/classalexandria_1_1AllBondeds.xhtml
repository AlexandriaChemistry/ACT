◆ histogramsToJson()

JsonTree alexandria::AllBondeds::histogramsToJson ( size_t maxSamples) const

The histograms of the values, in JSON For each interaction type a list with, for each identifier, its unit, the width of a bin, the number of values and the bins that have values: the middle of the bin and the number of values in it. With samples kept, a bin lists up to maxSamples of its values with the molecule, the data file of the calculation and the atoms they come from, and the number of the others (more). The atoms are numbered from one in the order of the molprop file, which has no shells or virtual sites (atoms), with their names (names).

Parameters
[in]maxSamplesThe most values that a bin lists
Returns
the histograms, with the key histograms
