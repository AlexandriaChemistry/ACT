Description

The rows of the parameter tables of the GPU kernels, for the processor and the GPU.

Each row has 8 numbers, made from the parameters of an interaction in internal units, see gpuPairEntry and gpuBondedEntry in forces_gpu.cpp, which use these functions. They exist only here, such that the GPU can make the rows itself from the parameters, with the same results. They only use arithmetic, in the same order as before, and neither throw nor use containers. The rows of Coulomb, made from the charges, are not here.
