alexandria::anonymous_namespace{optionsJsonTest.cpp}::CapturingRedirector Class Reference

Description

Output redirector that keeps what a program writes in memory.

Both the standard output of the help module and the files it exports are stored as strings, such that a test can inspect them without touching the file system.
