alexandria::Sensitivity2D Class Reference

#include <act/alexandria/sensitivity.h>

Description

The chi-squared as a function of two parameters The surface is the sum of the two one-dimensional parabolas plus a coupling term, chi2(x, y) = P_i(x) + P_j(y) - chi2_0 + a_ij (x - p_i) (y - p_j), where p_i and p_j are the original parameter values and chi2_0 the chi-squared there. The coupling a_ij is fitted to the corners of the grid, the points where both parameters differ from the original values. For a symmetric grid it is the mixed central difference, and it is exact for a quadratic surface.
