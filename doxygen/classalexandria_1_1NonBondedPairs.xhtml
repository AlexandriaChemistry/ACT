alexandria::NonBondedPairs Class Reference

#include <act/topology/nonbondedpairs.h>

Description

The non-bonded pairs of a topology All non-bonded interaction types (Coulomb, Van der Waals and their corrections) have the same pairs, those of the particles that are not excluded. They are stored once, as two particle indices each, and each interaction type has the positions of its pairs in that list, which are all of them unless the force field has no parameters for some, with the pair of particle types of each. The parameters are stored per pair of particle types, see PairTypes. The pairs of an interaction type are in the same order as the TopologyEntry objects of the type.
