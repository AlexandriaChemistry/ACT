alexandria::JsonTree Class Reference

#include <act/utility/jsontree.h>

Description

Simple class to produce JSON or text outputs The input is a tree structure that is filled in a program. A value is a string, a number or a boolean. Numbers are stored as text as well, such that the program decides on the number of digits, but they are written as JSON numbers, without quotes. Numbers that are not finite are written as null, since JSON has no way to write them. Each JsonTree can have either a value or objects but not both. If both are added a warning is printed. A tree without value and without objects is written as null, a tree with an empty string as value as "". The objects of a tree are written as the members of a JSON object, or, for a tree made with array(), as the elements of a JSON array. In an array the keys of the objects are not written. JSON serialization is performed using the nlohmann/json library.
