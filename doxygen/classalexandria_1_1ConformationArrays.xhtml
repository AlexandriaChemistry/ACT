alexandria::ConformationArrays Class Reference

#include <act/forces/conformationdata.h>

Description

Coordinates and forces of the conformations of a topology.

Component m of particle a in slot c is stored at (3*a+m)*stride + c, such that loops over conformations access memory contiguously and can be vectorized. The slots hold all conformations, or only those for which the shells did not converge yet, see CoordsEnergy::done, and conformation(c) is the conformation in slot c. The stride is the number of slots rounded up to a multiple of the explicit SIMD width. The extra slots are copies of the last one, they are computed but not used.
