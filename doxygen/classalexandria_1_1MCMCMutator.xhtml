void alexandria::MCMCMutator::mutateLockstep ( MsgHandler * msghandler,

const std::vector< ga::Genome * > & bestGenomes )
static

Run MCMC for several genomes at once, each with its own mutator The steps of all genomes are computed at once, see ACMFitnessComputer::calcDeviations. Each mutator draws the same random numbers as mutate, such that the result of each genome is that of mutate, except for where the relaxation of the shells starts from, see ForceComputer::setKeepShells. The mutators must not evaluate the test set.

Parameters
[in]msghandlerThe message and status handler
[in]mutatorsThe mutator of each genome, they share the fitness computer
[in,out]genomesThe genomes
[out]bestGenomesThe best genome of each
