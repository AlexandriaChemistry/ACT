alexandria::Sensitivity Class Reference

#include <act/alexandria/sensitivity.h>

Description

Sensitivity of the chi-squared to one force field parameter, determined by fitting a parabola chi2 = a p^2 + b p + c through chi-squared values computed for different values p of the parameter.

Determine whether the original parameter value is converged This is the case if the parabola curves upwards, and the parameter is within the tolerance of the minimum of the parabola. The minimum is limited to the bounds, such that a parameter at a bound is converged if the minimum is beyond that bound. Call computeForceConstants first.
