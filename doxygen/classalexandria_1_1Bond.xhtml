Public API | Code related to the MolProp class.

#include <act/molprop/topologyentry.h>

Description

Chemical bond in a molecule with associated bond order.

The chemical bonds in a molecule are stored here along with the bond order which together can be used for determining the atom types in a force field calculation. In the present implementation this data is generated by OpenBabel and stored in molprop files.
