alexandria::TrainProgress Class Reference

#include <act/alexandria/train_progress.h>

Description

Writes the progress of training to a file, for a program that follows it.

The file gets lines with one JSON object each, and each line is on disk as soon as it is written. The key "event" says what a line is:

  • "start", once, when the first population has its chi squared: the optimizer, the number of generations ("ngenerations"), of Monte Carlo iterations in each generation ("niterations", zero for the genetic algorithm on its own), of individuals ("population") and of parameters ("nparameters"), and the best chi squared of the population ("chi2").
  • "step", for steps of the Monte Carlo chain of the master process, a few times per second at most: the generation, from one, the iteration in that generation with the fraction of the parameters that were changed, the chi squared of the chain ("chi2") and the lowest one of the chain so far ("best").
  • "generation", at the end of each generation: the generation, from one, the number of generations, the lowest chi squared of all individuals so far ("best") and whether this generation lowered it ("improved"). Monte Carlo on its own is one generation.

A chi squared is an object with the value for the data set "train" and, when the optimizer computes it, for "test". The lines for steps and generations have the time since the start in "elapsed", with its unit.

Only the master process has such an object. The file is made by start(), such that there is none when nothing is trained.
