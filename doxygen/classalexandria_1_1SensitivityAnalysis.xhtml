Perform a sensitivity analysis by systematically changing all parameters and re-evaluating the . The results are stored for json() and write(), the log file gets a summary only.

Parameters
[in]msghandlerThe message and status handler
[in]siiThe force field and parameter information
[in]fitCompComputes the chi-squared
[in]genomePointer to genome
[in]imsDataset to perform sensitivity analysis on
[in]modeThe analysis to do: 1D changes each parameter on its own, 2D also each pair of parameters, see Sensitivity2D. With No nothing is done.
[in]quietDo not print to log file
[in]useMiddlemenWhether the middlemen compute part of the deviations for the training set. They have to be waiting for work from the master, see ACTMiddleMan::run.
Returns
true if all parameters are converged, that is the parabola through the chi2 of each of them curves upwards, and the parameter is within 5% of its range of the minimum of the parabola, limited to the bounds of the parameter. See Sensitivity::checkConvergence. In 2D all pairs have to be converged as well, see Sensitivity2D::checkConvergence.
