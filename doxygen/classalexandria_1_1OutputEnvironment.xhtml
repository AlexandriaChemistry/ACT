alexandria::OutputEnvironment Class Reference

#include <act/utility/output_environment.h>

Description

The output environment of a command line, or one with its defaults.

The functions that write xvg files need the output environment that the parser of the command line makes. A program without a command line gets one with the defaults of the command line (-xvg xmgrace), which is freed with this object.
