alexandria::Symcharges Class Reference

#include <act/forcefield/symcharges.h>

Description

Rule for symmetrizing charges Atoms of element attached_ bonded to an atom of element central_ get equal charges if there are exactly numattach_ of them, e.g. the hydrogens in a methyl group.
